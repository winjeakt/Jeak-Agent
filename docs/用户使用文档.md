# Jeak Agent 用户使用文档

> AI Native 本地化编程助手桌面平台

## 1. 应用简介

Jeak Agent 是一款基于 **DeepSeek API** 的本地化 AI 编程辅助桌面应用，以 **Agent Plugins 1.0** 为标准，构建开放、安全的插件生态系统。

核心特点：

- **AI Native**：内置 DeepSeek 流式对话，支持代码解释、上下文感知
- **插件优先**：所有功能通过插件扩展
- **安全第一**：插件运行在多层沙箱内（进程隔离 + 上下文隔离 + 权限白名单）
- **本地化**：API Key 仅存于本地加密存储，不经手任何第三方服务器

## 2. 系统要求

| 系统 | 版本 | 架构 |
|------|------|------|
| Windows | 10 / 11 | x64 |
| macOS | 11（Big Sur）及以上 | Apple Silicon（arm64）/ Intel（x64） |
| Linux | 主流发行版 | x64 |

## 3. 安装

安装包均发布在 [GitHub Releases](https://github.com/winjeakt/Jeak-Agent/releases)。

### 3.1 Windows

1. 下载 `Jeak-Agent-Setup-<版本>.exe`
2. 双击运行，按安装向导完成安装（可选择安装目录）
3. 安装完成后桌面会自动创建快捷方式

> 首次启动若出现 Windows SmartScreen 提示，点击「更多信息」→「仍要运行」即可。

### 3.2 macOS

1. 下载对应架构的 `.dmg`（Apple Silicon 选 `arm64`，Intel 选 `x64`）
2. 打开 dmg，将「Jeak Agent」拖入「应用程序」文件夹
3. 首次打开若提示「无法验证开发者」：
   - 打开「系统设置 → 隐私与安全性」
   - 在底部找到被拦截的提示，点击「仍要打开」

### 3.3 Linux

1. 下载 `Jeak-Agent-<版本>.AppImage`
2. 赋予执行权限：`chmod +x Jeak-Agent-*.AppImage`
3. 双击运行，或在终端中执行 `./Jeak-Agent-*.AppImage`

## 4. 快速开始

1. **启动应用**：双击桌面图标或从应用菜单启动
2. **配置 API Key**：点击对话面板右上角 ⚙ 打开设置，填入 DeepSeek API Key
   - 获取地址：<https://platform.deepseek.com/>
3. **选择模型**：`deepseek-chat`（通用对话）或 `deepseek-reasoner`（深度推理）
4. **打开项目**：通过「文件」菜单或文件树打开一个项目目录
5. **开始使用**：在右侧对话面板提问，或选中代码后按 `Ctrl+E` 让 AI 解释代码

> API Key 由主进程加密存储，仅用于请求 DeepSeek 服务，不会暴露给渲染进程或插件。

## 5. 核心功能

### 5.1 AI 对话

- 在右侧对话面板与 AI 进行流式对话
- AI 可感知当前打开的文件和项目上下文
- 选中编辑器中的代码后按 `Ctrl+E`，AI 会解释该段代码

### 5.2 代码编辑器

- 基于 Monaco Editor，支持语法高亮、智能提示
- AI 解释浮层：选中代码后调用解释
- 问题面板：展示编辑器的诊断信息

### 5.3 终端

- 内置终端服务，可直接运行命令

### 5.4 插件系统

- 遵循 Agent Plugins 1.0 标准
- 内置示例插件：代码格式化、Git 辅助、ESLint 集成
- 通过「设置 → 插件管理」启用、运行或卸载插件

## 6. 设置

在对话面板右上角 ⚙ 打开设置，可配置：

| 设置项 | 说明 |
|--------|------|
| API Key | DeepSeek API Key（加密存储） |
| 模型 | `deepseek-chat` / `deepseek-reasoner` |
| 主题 | 界面主题 |
| 语言 | 界面语言 |

## 7. 自动更新

应用内置自动更新能力，更新源为 GitHub Releases。

**检查更新**：点击菜单栏「帮助 → 检查更新」。

更新流程：

1. 检查到新版本后，弹窗询问是否下载
2. 确认后自动下载更新包
3. 下载完成后询问是否重启安装
4. 确认后应用自动重启并完成更新

> 注意事项：
> - 开发模式（`npm run dev`）下无法检查更新，请使用打包后的应用
> - macOS 版本若未配置开发者证书签名，自动更新功能暂不可用；请手动下载安装包更新

## 8. 插件系统

### 8.1 插件目录

插件存放在 `~/.jeak/plugins/` 目录。

### 8.2 插件结构

```
my-plugin/
├── plugin.json          # 插件清单（名称、版本、权限、入口、命令）
├── main.js              # 插件入口脚本
└── SKILL.md             # 技能说明文档
```

### 8.3 安装插件

```bash
cp -r my-plugin ~/.jeak/plugins/
```

重启应用后，在「设置 → 插件管理」中启用、运行或卸载插件。

## 9. 常见问题（FAQ）

**Q1：提示 API Key 无效？**
请检查 DeepSeek 控制台中的 Key 是否正确，以及账户余额是否充足。

**Q2：AI 无法响应？**
检查网络连接，以及 API Key 是否有效。可在设置中重新填写 Key。

**Q3：检查更新失败？**
- 确认当前使用的是打包后的应用（非开发模式）
- 检查网络连接能否访问 GitHub
- 若仍失败，可手动前往 GitHub Releases 下载最新安装包

**Q4：macOS 提示「无法验证开发者」？**
见「3.2 macOS 安装」中的处理方式。

**Q5：Windows SmartScreen 提示风险？**
当前版本未配置代码签名证书。点击「更多信息 → 仍要运行」即可，后续正式版本会加入签名。

**Q6：插件无法加载？**
检查插件目录结构是否完整、`plugin.json` 是否合法，以及是否已授予所需权限。

## 10. 卸载

### Windows
「设置 → 应用 → 已安装的应用」中找到「Jeak Agent」，点击卸载。

### macOS
将「应用程序」中的「Jeak Agent」拖入废纸篓。

### Linux
删除 `.AppImage` 文件即可。如需清理配置，删除 `~/.jeak/` 目录。
